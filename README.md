# Hamburguesas Mahanto

**Hamburguesas Mahanto** es una landing page de alta gama y catálogo digital diseñado exclusivamente para una hamburguesería artesanal premium. Este proyecto fusiona una interfaz visualmente cautivadora con una lógica de personalización avanzada, optimizada para ofrecer una experiencia de usuario fluida y convertir antojos en pedidos directos a través de WhatsApp.

---

## 🚀 Características Principales

### 💎 Experiencia Visual Premium & UI/UX

- **Hero Dinámico:** Carrusel de imágenes en alta definición con transiciones suavizadas (Cross-fade) que destacan el producto estrella desde el primer segundo.
- **Diseño Moderno:** Implementación de *Glassmorphism*, fondos oscuros sofisticados con contrastes vibrantes y tipografía audaz que evoca el concepto de comida urbana premium.
- **Enfoque Mobile-First:** Interfaz totalmente adaptativa y pulida para dispositivos móviles, garantizando que el usuario pueda navegar por el menú y ordenar con una sola mano.
- **Animaciones Fluidas:** Uso de `Framer Motion` para efectos de scroll reveal y transiciones sutiles que mejoran la retención del usuario.

### 🍔 Sistema de Personalización de Combos e Ingredientes

- **Configurador de Hamburguesas:** Lógica avanzada que permite al usuario seleccionar el término de la carne, tipo de pan y adiciones premium (extra tocino, doble queso, salsa de la casa).
- **Gestión de Combos Dinámicos:** Interfaz interactiva para armar combos, permitiendo elegir el tipo de acompañamiento (papas francesas, rústicas, aros de cebolla) y bebida sin fricciones.
- **Validación de Adiciones:** Control preciso del inventario de ingredientes extra en el carrito, actualizando los costos en tiempo real de manera transparente.

### 🛒 Carrito y Checkout Optimizado para Gastronomía

- **Edición en Tiempo Real:** Los clientes pueden modificar ingredientes, tamaños o eliminar productos directamente desde el carrito de compras sin perder el progreso de su orden.
- **Integración Estratégica con WhatsApp:** Módulo automatizado que recopila el pedido y genera un mensaje perfectamente estructurado con el desglose detallado (término de la carne, extras, combos), datos de entrega (domicilio o retiro) y método de pago.
- **Feedback Elegante:** Alertas del sistema controladas por `SweetAlert2` para notificar de forma limpia cuando un producto se añade, edita o si se requiere rellenar un campo obligatorio.

---

## 🛠️ Stack Tecnológico

- **Frontend:** React.js + Vite
- **Estilos:** CSS3 Vanilla + Bootstrap 5 (React-Bootstrap) / Tailwind CSS
- **Animaciones:** Framer Motion
- **Iconografía:** Lucide React
- **Alertas:** SweetAlert2
- **Gestión de Estado:** Context API de React
